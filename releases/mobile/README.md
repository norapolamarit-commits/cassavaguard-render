# CassavaGuard Mobile builds

- `CassavaGuard-Android-v1.0-debug.apk` — Android test/sideload build, signed with the Android debug key.
- `SHA256SUMS.txt` — checksum for verifying the downloaded APK.

See `docs/MOBILE_BUILD_TH.md` for installation and build instructions. iOS source is under `ios/`; an installable iOS package must be signed by the owner's Apple Developer account in Xcode.
